# 0.3.0 — 2026-10-13

## Added

- **`docgen_list_form_fields`** returns exact nested AcroForm names, types, required flags and choice options from a base64 or HTTPS PDF, without changing or storing it; signatures and buttons are discovery only. ([#10](https://github.com/cyanheads/docgen-mcp-server/issues/10))

## Changed

- **Semantic failures** use `ValidationError` (`-32007`) for `empty_workbook`, `invalid_source`, `invalid_sheet_name`, `invalid_pdf_source`, `not_a_form`, `template_render_failed` and `document_too_large`. Update clients branching on `-32602`; malformed arguments retain `InvalidParams`. ([#18](https://github.com/cyanheads/docgen-mcp-server/issues/18))
- **Capability titles** identify each tool and the document resource separately. ([#17](https://github.com/cyanheads/docgen-mcp-server/issues/17))
- **Framework guidance** synchronizes input repair, error bounds, telemetry, canvas and release instructions.

## Fixed

- **Spreadsheet coercion** recognizes trimmed boolean strings, preserves unknown strings, leaves blank numeric cells blank and keeps numeric dates as decimal text. ([#8](https://github.com/cyanheads/docgen-mcp-server/issues/8))
- **Column descriptions** document the union of all row keys in first-seen order when no column spec is supplied. ([#12](https://github.com/cyanheads/docgen-mcp-server/issues/12))
- **PDF text** reports `degraded` when characters are replaced on body, list, table, header or footer surfaces; unsupported header/footer text produces a valid PDF. Smart-punctuation transliteration alone remains non-degraded. ([#9](https://github.com/cyanheads/docgen-mcp-server/issues/9))

## Security

- **HTTPS PDF sources** connect only to a vetted address at every redirect hop with original TLS identity preserved; equivalent blocked IPv6 forms, the full link-local range and cancelled requests are handled consistently. ([#11](https://github.com/cyanheads/docgen-mcp-server/issues/11))
