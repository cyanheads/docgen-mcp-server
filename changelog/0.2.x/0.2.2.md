# 0.2.2 — 2026-08-21

## Changed

- **MCP runtime** — `@cyanheads/mcp-ts-core` ^0.10.9 → ^0.12.3 moves the server to `@modelcontextprotocol/server` ^2.0.0 and its SDK v2 handler, schema, and error contracts; the existing four-tool and one-resource surface is unchanged.
- **Verification** — smoke coverage now executes every definition, an integration suite exercises success and declared error envelopes, and property-based fuzzing covers document lookup; HTML/markdown layout, AcroForm choice fields, and TypeScript 7 compatibility gained focused regression coverage.
- **Packaging** — Bun 1.3.2 → 1.4.0 and TypeScript ^6.0.3 → ^7.0.2 update the build baseline; Docker builds use BuildKit dependency caches and omit optional peers, while MCPB cleanup strips platform-specific DuckDB bindings to keep bundles portable.
- **Repository metadata** — added contributor, conduct, security, funding, and line-ending policies; package and plugin manifests now use the canonical author identity, and the license copyright year is 2026.
