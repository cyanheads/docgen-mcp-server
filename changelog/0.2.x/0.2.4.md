# 0.2.4 — 2026-10-07

## Changed

- **Framework upgrade** — adopts JSON-stringified object repair (0.13.9), automatic declared recovery hints and tool error request IDs (0.13.10), independent generated request IDs and path-first resource validation errors (0.13.12), and removal of framework-added error root causes (0.13.13).
- **Tool recovery** — handlers rely on automatic declared hints; contract tests check both structured and text error surfaces.
- **Docker** — cross-installs production dependencies on the build platform, installs OpenTelemetry at framework peer ranges, and prunes musl-only packages from glibc images.
- **Plugin configuration** — Claude and Codex plugins expose the five document-rendering environment settings.
- **Development tooling** — refreshes framework scripts and skills, separates CodeQL analyses by language, and aligns environment and telemetry documentation.
- **Package contents** — excludes built MCPB bundles from npm tarballs and cache/log files from bundles; ignore rules cover environment files and registry tokens.

## Fixed

- **Registry launch metadata** — npm entries invoke the package bin through `npx`; the HTTP entry fixes `MCP_TRANSPORT_TYPE=http`.
- **Timeout regression test** — advances a fake clock while a small real workbook serialization remains pending instead of relying on a large workload.
- **Storage documentation** — names the existing `doc/meta/` and `doc/blob/` keys.
