# 0.4.0 — 2026-11-11

## Added

- Add the docgen-guide workflow skill, available over MCP as skill://docgen-guide/SKILL.md.
- **`docgen_list_form_fields`** reports available tooltips, text length limits, checkbox export values, stored values and first-widget pages. ([#28](https://github.com/cyanheads/docgen-mcp-server/issues/28))
- **`docgen_fill_form`** accepts unambiguous short names and case variants, and lists them in `resolvedFields`. ([#32](https://github.com/cyanheads/docgen-mcp-server/issues/32))
- **HTTPS PDF sources** accept `application/octet-stream` when the body starts with `%PDF-`. ([#31](https://github.com/cyanheads/docgen-mcp-server/issues/31))

## Changed

- **`docgen_fill_form`** reports fixed dropdowns made editable by custom text in `madeEditableFields` and includes a notice with the value. ([#33](https://github.com/cyanheads/docgen-mcp-server/issues/33))
- **Filesystem storage** copies existing data into `_v2/` on first start after upgrading from mcp-ts-core 0.13.21 or earlier. Allow room for both copies and upgrade every instance sharing the path before resuming writes.

## Fixed

- **HTTPS PDF sources** try other vetted addresses after TCP connection failures, including IPv4 fallback when IPv6 is unreachable. ([#21](https://github.com/cyanheads/docgen-mcp-server/issues/21))
- **Checkbox assignments** accept common checked strings and the PDF's export value. Unrecognized values leave the box unchecked and produce a notice. ([#26](https://github.com/cyanheads/docgen-mcp-server/issues/26))
- **Invalid form assignments** return one `invalid_field_value` error with field constraints and a recovery hint. Radio and option-list assignments accept unique case-insensitive choices. ([#27](https://github.com/cyanheads/docgen-mcp-server/issues/27))
- **Flattened PDFs** keep rendered field text and remove obsolete widget annotation references.
- **Document retrieval guidance** directs callers to the resource URI for bytes above the inline size limit.
