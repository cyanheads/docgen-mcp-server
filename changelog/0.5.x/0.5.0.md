# 0.5.0 — 2026-11-21

## Changed

- **PDF templates.** Templates that previously printed unsupported tags literally now return `template_render_failed`. To print a literal tag alongside interpolated values, encode its opening braces as `&#123;&#123;`. ([#24](https://github.com/cyanheads/docgen-mcp-server/issues/24))

## Fixed

- **HTML PDFs.** Preserve block order, nested lists, hard breaks, preformatted whitespace, and decoded character references. Table rows can continue across pages without duplicating cell text. ([#22](https://github.com/cyanheads/docgen-mcp-server/issues/22), [#30](https://github.com/cyanheads/docgen-mcp-server/issues/30))
- **Markdown PDFs.** Render inline text, nested and checked task items, and raw HTML through the shared layout. Print link destinations once, including links inside preformatted HTML. ([#23](https://github.com/cyanheads/docgen-mcp-server/issues/23))
- **PDF interpolation.** Double braces insert literal text and retain supported dotted paths, including paths through empty-string keys. Migrate intentional HTML fragments in mixed templates to triple braces. ([#24](https://github.com/cyanheads/docgen-mcp-server/issues/24))
- **PDF fonts.** Render Helvetica's supported WinAnsi characters, including `€`, `™`, and `Œ`, without degradation. ([#25](https://github.com/cyanheads/docgen-mcp-server/issues/25))
- **Spreadsheet date columns.** Validate full calendar dates and timestamps, interpret offsetless values as UTC, retain invalid strings as text, and write whitespace-only values as blank cells. ([#29](https://github.com/cyanheads/docgen-mcp-server/issues/29))
- **PDF page geometry.** Report `invalid_page_margins` when the body cannot fit. Wrap headers, footers, and page numbers within the page and reserve enough space to keep them clear of body text. ([#30](https://github.com/cyanheads/docgen-mcp-server/issues/30))
